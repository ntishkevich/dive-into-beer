# Погружение в ПИВАС

Визуальный атлас истории пива, пивных школ, стилей и языка этикеток. Текст подготовлен для самостоятельной публичной страницы.

Выбран вариант B — «Атлас»: боковое оглавление на компьютере, меню «Содержание» на телефоне, название читаемого раздела и индикатор прокрутки в шапке. Обложка с бокалами, исходная палитра и семейства шрифтов сохранены. Публичная страница собирается сразу в этой компоновке.

## С чего начать

- `index.html` — готовая главная страница атласа. Откройте её в браузере. Навигация, сравнение хмельных профилей и самопроверка работают без подключения к сети.
- Хронология России и Беларуси находится в разделе 02.3, на странице 5 PDF. Пять очерков о российском и белорусском пивоварении собраны в разделах 03.5 и 03.6, на страницах 10 и 11. [Записка с источниками](reference/beer-history-russia-belarus-research.md).
- В памятке есть восемь баек и исторических эпизодов с пояснением статуса источников. Памятка начинается на странице 20 PDF.
- [Пять слов из пивного меню](lessons/0001-reading-beer-menu.html) — короткий урок на 5–7 минут.

Перед написанием и редактурой прочитай [редакционное руководство](reference/editorial-guide.md): голос автора, работа с фактами, байками и терминами, примеры и внешние референсы. Цель и границы атласа описаны в [MISSION.md](MISSION.md), источники с пояснениями собраны в [RESOURCES.md](RESOURCES.md).

## Исходные материалы

Содержимое атласа хранится в `assets/beer-data.json`. Общие стили и механика заданий находятся в `assets/`. Оглавление и номера разделов сайта и PDF формируются из `assets/atlas-chapters.json`.

- `node scripts/build-atlas.cjs` обновляет `index.html`, HTML урока и самостоятельный файл `output/beer-atlas.html`.
- `python scripts/build-pdf.py` создаёт `output/beer-atlas.pdf` для чтения и печати. Нужны ReportLab, pypdf и шрифты Arial и Georgia из Windows.
- `node scripts/preview-atlas.cjs` запускает локальный просмотр.

## Публикация и проверка

В GitHub Pages выберите ветку `main` и папку `/(root)` в **Settings → Pages**. В корне уже есть готовый `index.html` и `.nojekyll`, поэтому сайт открывается без сборки. [Инструкция для GitHub Pages](assets/site-readme.md).

После обновления HTML запустите `node scripts/audit-atlas.mjs`, затем `node scripts/build-site-audit.cjs` и `python scripts/package-deliverables.py`. Для локального аудита нужны Chrome и Node.js 22.19 или новее. Lighthouse можно установить командой `npm install --prefix tmp/lighthouse-tools lighthouse@13.6.0`. Упаковщик сверяет SHA-256 HTML с обоими отчётами и проверяет порог 90. Архивы `beer-site.zip` и `beer-course.zip` появляются в локальной папке `output/`. Для обновления только комплекта исходников используйте `--course-only`.

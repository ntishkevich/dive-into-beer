# Погружение в ПИВАС

Русскоязычный визуальный атлас истории пива, пивных школ, стилей и языка этикеток. В нём можно сравнить хмелевые профили, проверить себя и открыть карточки с источниками. Готовый атлас находится в [index.html](index.html) и открывается прямо в браузере.

- [`assets/`](assets/) — тексты, данные о стилях и источниках, структура глав, стили CSS и JavaScript для навигации и интерактивных заданий.
- [`scripts/`](scripts/) — генерация страницы и PDF, локальный просмотр, браузерные проверки, аудит Lighthouse и упаковка сайта.
- [`reference/`](reference/) — редакционное руководство, журнал правок и исследовательские материалы.
